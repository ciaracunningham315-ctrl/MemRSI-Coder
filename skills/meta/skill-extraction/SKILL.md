---
name: skill-extraction
description: Extract reusable coding procedures from evidenced task traces and maintain a compact skill library.
---
Read the original task trace and acceptance outcomes. Separate verified fixes from failed attempts.
Check existing skills before creating a new one. Preserve repository and version applicability.
Prefer revision to duplicate creation. Generalize only when evidence supports multiple repositories.
Produce a candidate with explicit triggers, procedure, limitations, source event identifiers and parent version.
Never change tool permissions, evaluation rules or active versions. Submit candidates for isolated paired evaluation.
