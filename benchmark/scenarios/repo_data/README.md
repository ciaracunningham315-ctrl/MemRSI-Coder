# repo_data 四阶段题集

主题是多流程数据处理中的空值、类型转换、金额精度和数据格式迁移。四个阶段各自从固定快照启动；前一阶段 Agent 的工作区修改不会自动进入下一阶段。

| 阶段 | 业务流程 | 主要变化 |
|---|---|---|
| T1 Seed | 销售汇总 | 金额精度与既有输入契约 |
| T2 Transfer | 出库清单 | 未称重记录与状态表达 |
| T3 Stale | 合作方对账 | 输入格式和字段表示迁移 |
| T4 Held-out | 月结导入 | 多来源字段组合与兼容性 |

每阶段的 `task.md` 描述当前业务目标；当前代码、仓库说明和数据契约共同构成公开输入。公开检查命令为：

```bash
python -m unittest discover -s tests
```

隐藏验收、固定回归、参考修复和错误补丁位于 `benchmark/private/`。阶段 Git 包位于 `benchmark/git_stage_packages/`。离线验证记录的是题集和判分链路可运行性，不是 Agent 能力或模型效果成绩。
