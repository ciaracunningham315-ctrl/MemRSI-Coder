# repo_api 四阶段题集

本题集是标准库 Python 库存 JSON API，不依赖 EvoCode 服务。版本为 `repo_api_contracts_v2_2026-11-06`。每个 `code/` 是独立固定起点，上一题 Agent 补丁不会进入下一题；既有业务路由随阶段累积保留。公开检查命令为 `python -m unittest discover -s tests`。

| 阶段 | 新任务 | 独立业务契约与参考修复 |
|---|---|---|
| T1 seed | 预约 | 数量域与上限、错误定位、失败不消耗预约编号；参考修复涉及数量校验、错误构造、预约服务 |
| T2 transfer | 带损坏验收的退货 | 总量与损坏量的不同下限、组合字段路径、仅可用件入库；参考修复涉及校验声明、错误构造、退货服务 |
| T3 stale | 嵌套暂存与优先级 | 嵌套数量错误定位、优先级精确取值、跨路由编号及失败状态；参考修复涉及暂存服务和优先级校验 |
| T4 heldout | 批量预约 | 非空批次、全量输入校验优先、重复 SKU 累计检查、失败事务隔离；参考修复涉及批次校验、批量服务和库存事务 |

任务说明描述业务问题；求解者可以从 README 找到 `code/docs/api-contract.md`，独立发现本版本所有输入输出、顺序与状态契约。公开测试只覆盖基本可用性。实现按路由、校验、商品目录、HTTP 响应、库存事务分模块，新增路由使用现有相关逻辑，未在入口顶部摆放未使用的答案函数。

私有验收与固定回归位于 `benchmark/private/`。回归集合随阶段累积，覆盖此前业务的成功与错误输入；故障起点应通过固定回归，参考修复应通过全部验收与回归。三类错误补丁分别删除校验、吞异常伪装成功、硬编码公开样例。`private/references/repo_api/qualification/` 保存本版本离线准入的实际命令与日志，不代表 Agent 能力成绩。T4 不参与此前 Task/Meta Skill 的学习、选择或发布。

manifest 路径相对 Benchmark 根目录。`reference_dir` 和每个坏补丁 `overlay_dir` 均为完整树，允许文件删除。隐藏测试只注入可信干净副本；Agent 只获得当期代码、公开规范和题面。判分以可观察契约为准，不限制 Agent 必须修改某个文件或修改若干文件。对参考修复逐文件移除/单独应用的消融仅说明该参考实现中的独立缺陷约束，不能证明所有合理解法都必须跨文件修改。

T3 将历史 `api/errors.py` 迁移为 `api/faults.py`，`require_count` 改名为 `read_count`，错误元数据由 field 改为 path。`api/http.py` 中相关函数与文件字节全阶段保持不变，是有效旧经验对照。预期 paths/symbols/content 失效必须来自真实工具编辑记录与历史证据提取，再调用实际适用性检查核对；离线全文件 diff 不是真实 Agent 轨迹，Git commit 不同本身也不能证明失效。
